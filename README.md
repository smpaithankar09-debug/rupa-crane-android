# Rupa Crane Service Android App

This is a ready Android project for the Rupa Crane Service API.

API base:
https://rupa.tejasinfotech.in/api/

Current build flow is prepared for GitHub Actions so Android Studio is not required on the user's PC.

Build:
1. Upload this project to a GitHub repository.
2. Open Actions -> Build Rupa APK -> Run workflow.
3. Download the `RupaCrane-debug-apk` artifact.

The app currently provides API login, dashboard, customers, products/spare parts, documents list, and logout. Full quotation/invoice entry screens can be added next.
